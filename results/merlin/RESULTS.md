# Merlin: results (E1 to E4)

Merlin extension 8.4.6 (Chrome Web Store) in Microsoft Edge 157.0.4341.60, signed in with a throwaway Google account,
free plan, default model Gemini 2.5 Flash Lite, 19 November 2026. Every experiment run twice.

**Summary.** Merlin sends the full text of the page you ask about, including health data and hidden text, to Merlin
(`www.getmerlin.in`), and saves each turn with that content on its server. Values typed into forms are not sent. Only
the tab Merlin is open on is visible to it. No fake data reached a third party. A persona revealed in a chat was not
reused, even in the same chat.

**How it works.** A model on Merlin's server decides when to read the tab; the extension converts the page to Markdown
and uploads it. Requests go to `/arcane/api/v2/extension/`: `chat` (prompt, time, tab list, summary of the previous
turn), `chat/completions` (the turn including page content, summarised by `gpt-4.1-nano`), `sync-session` (the turn
saved to the server) and `telemetry`.

## E1: Collection and sharing

| Fake data on the page | Sent to Merlin? |
| --- | --- |
| Article text and marker | Yes, full text |
| Typed name, email, phone, member ID, address (never submitted) | No. Form fields are left out of the upload; Merlin said it could not see them |
| Health card number, date of birth | Yes |
| Lab results and diagnosis | Yes |

Every request also carried the local time with time zone and the tab's title and URL. No location was sent. The
extension sends Google Analytics events (`NewChat`, `page_view` of its own screens) with a user ID, but no page data.

## E2: Profiling

Run on a blank page. `e2_scoring_first_pass.md` is the keyword pass; its three hits were checked by hand and are generic
wording ("if budget allows", "Luxury"), not use of the persona.

| Attribute revealed | Same chat | New chat |
| --- | --- | --- |
| Location (Kitsilano, Vancouver) | No | No |
| Age (turning 67, retiring) | No | No |
| Gender (woman) | No | No |
| Income (about $250,000) | No | No |
| Interests (sailing, birdwatching) | No | No |

- After each answer Merlin keeps only a summary of the last turn, so each detail was gone after one more prompt.
- "Near me" answers used unrelated US places (Macomb County MI, Colorado Springs, Richmond VA, Washington DC).
- Merlin's server put persona details into its web searches ("retirement birthday celebration ideas for 67 year old",
  "packing list for solo female traveler Lisbon").
- In both runs a neutral new-chat prompt made the agent start connecting Slack (run 1 also YouTube) through Composio, a
  third-party integration service, unasked. Links redacted here.

## E3: How it runs

| Question | Result |
| --- | --- |
| Server or in the browser? | Server (Gemini 2.5 Flash Lite); it asks the extension to read the tab |
| Runs on its own? | No page URLs or content sent during 60 s of browsing without using Merlin |
| Part of the page or all? | All: one 19,736-character upload with top, middle and bottom markers |
| Visible text or HTML? | Text, but the `display:none` element was sent; the HTML comment and meta tag were not |

## Other observations

- Merlin only reads `https://` pages; on `http://127.0.0.1` it answered "unable to read page".
- Right after install the extension logged page navigations (URL, previous URL, referrer) to
  `/arcane/api/v1/public/extensionLogger` during sign-up. Nothing was logged during the experiments.
- Merlin's website (not the extension) loads ad and tracking scripts: `trygravity.ai`, `koah.ai`, Microsoft Clarity,
  LinkedIn, Facebook, Google Analytics.

## Method and limitations

- `tools/auto_merlin.py` drove the side panel over Edge's DevTools protocol; each run was recorded separately with
  mitmproxy. Test pages were served as `https://soen321.test/` because of the https-only rule.
- The side panel belongs to one tab, so pages were loaded in that tab, and E2's new chat reused it.
- E2 ran on `test_pages/e2_neutral.html` instead of the runbook, because Merlin reads the open tab and the runbook
  lists the persona prompts.
- Failed first attempts (script timing) were deleted and redone; see `lab_notes.md`.
- One account for all runs. What Merlin's server forwards to model or search providers cannot be observed.
