# Copilot in Edge: results (E1 to E4)

Microsoft Edge 157.0.4341.46, Copilot sidebar signed in with a Microsoft account, 13 November 2026.
E1, E3 and E4 run twice; E2 run four times (run 3 complete, runs 1, 2 and 4 partial; see `lab_notes.md`).

**Summary.** Copilot sends the full visible text of the page you ask about, including values typed into unsubmitted
forms and health data, to Microsoft (`substrate.office.com`). Every prompt also carries the URL and title of every open
tab, and in one run another tab's full content was uploaded when the user asked what else was open. All traffic went
to Microsoft servers; no third-party trackers appeared. A persona revealed earlier in a chat was used in nearly every
later answer in that chat, but not in a new chat.

## E1: Collection and sharing

| Fake data on the page | Sent to Microsoft? | In the upload |
| --- | --- | --- |
| Article text and marker | Yes | Full text |
| Typed name, never submitted | Yes | As typed |
| Typed email | Yes | As typed |
| Typed member ID | Yes | As typed |
| Typed phone | No | `[Phone Number Redacted]` |
| Typed address | No | `[Address Redacted]` |
| Health card number, date of birth | Yes | As on page |
| Lab results and diagnosis | Yes | As on page |

Every prompt also carried the time zone and language. Microsoft's server already held a location for the user
(`userLocation: CA-QC`) and included it in its own requests; it was never typed.

## E3: How it runs

| Question | Result |
| --- | --- |
| Server or in the browser? | Server. After each prompt the server sends `fetch_browser_content` naming a tab, and the browser uploads that tab's content |
| Runs on its own? | No page content sent during 60 s of browsing without using Copilot; the open sidebar sent 5 telemetry posts without page URLs or content |
| Part of the page or all? | All: one 19,618-character upload with top, middle and bottom markers |
| Visible text or HTML? | Visible text only; markers in an HTML comment, a meta tag and a hidden element were not sent |

## E4: Cross-tab

Every prompt carried a `messageAnnotations` list of all open tabs (URL, title, active, last used).

| Prompt on tab A | Run 1 | Run 2 |
| --- | --- | --- |
| "Summarize this page" | Only tab A's content uploaded; tab B's URL and title in the tab list | Same |
| "What else do I have open in my browser right now?" | Server asked for 3 tabs; tab B's full content uploaded and repeated in the answer | No content requested; tab B named from the tab list only |

## Method and limitations

- A script (`tools/auto_copilot.py`) drove the sidebar over Edge's DevTools protocol; each run was recorded separately with mitmproxy. The Edge window stayed open between runs; each run started with a new chat and fresh tabs.
- One Microsoft account for all runs, so Copilot memory could carry over (none was seen in new chats).
- E2 runs 1 and 2 stopped early on Copilot's multiple-choice follow-up questions (fixed for runs 3 and 4); E2 run 4's new-chat part stopped at the free account's daily usage limit.
- A leftover error tab from the recording restarts appears in the E4 tab lists.

(per-run uploads, markers and destinations, generated by `analysis/copilot_report.py`).
